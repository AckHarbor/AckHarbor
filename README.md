# AckHarbor™ Academy

AckHarbor™ Academy teaches healthcare interface work with HL7® v2 and FHIR®: free browser tools,
practice data and self-paced online courses. Everything uses synthetic (fictional) data only.

Website: **[ackharbor.com](https://ackharbor.com)**

## Free tools and resources

- [Free HL7® v2 message viewer (AckHarbor Spyglass™)](https://ackharbor.com/hl7-message-viewer/)
- [Free FHIR® R4 JSON viewer (AckHarbor™ Chart™)](https://ackharbor.com/fhir-json-viewer/)
- [Free Harbor Engine Sandbox](https://ackharbor.com/download), a practice interface engine
- [Free AckHarbor™ Healthcare Agents Starter Kit](https://ackharbor.com/starter-kit) (Apache-2.0)

## Courses

- [AckHarbor™ Healthcare Agents Course](https://ackharbor.com/healthcare-agents/): build automated and AI software agents on HL7® FHIR®
- [All courses and the full syllabus](https://ackharbor.com/syllabus/)

## Public repositories

| Repository | What it is |
|---|---|
| [ackharbor-spyglass](https://github.com/AckHarbor/ackharbor-spyglass) | Offline HL7® v2 message viewer that names every segment and field. |
| [ackharbor-chart](https://github.com/AckHarbor/ackharbor-chart) | Offline FHIR® R4 JSON viewer with plain-English notes. |
| [harbor-engine-sandbox](https://github.com/AckHarbor/harbor-engine-sandbox) | Practice HL7® v2 interface engine that runs in your browser. |
| [healthcare-agents-starter-kit](https://github.com/AckHarbor/healthcare-agents-starter-kit) | HL7® v2 to FHIR® R4 interface engine and rule-based healthcare agents (Apache-2.0). |
| [hl7-v2-samples](https://github.com/AckHarbor/hl7-v2-samples) | Fictional HL7® v2.5 sample messages and a FHIR® R4 Patient example. |
