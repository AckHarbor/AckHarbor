# AckHarbor™ Academy

AckHarbor™ Academy teaches healthcare interface work with HL7® v2 and FHIR®: free browser tools,
practice data and self-paced online courses. Everything uses synthetic (fictional) data only.

Website: **[ackharbor.com](https://ackharbor.com/?utm_source=github&utm_medium=profile_readme&utm_campaign=github_profile)**

## Start here (free)

- 📄 **[Free HL7® v2 + FHIR® R4 Quick Reference (PDF)](https://ackharbor.com/quick-reference/?utm_source=github&utm_medium=profile_readme&utm_campaign=github_profile&utm_content=quick_reference)**: a one-stop cheat sheet for segments, fields, ACK codes and core FHIR R4 resources
